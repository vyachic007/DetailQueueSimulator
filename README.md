# Лабораторная работа №1: Моделирование очереди обработки деталей

## Описание проекта

Данная программа моделирует работу технологической установки, обрабатывающей детали различных типов. В основе реализации лежит структура данных "очередь", которая может быть реализована как на основе массива, так и на основе связного списка.

Каждая деталь содержит:
- Код детали (строка длиной 4 символа)
- Время обработки (целое положительное число)

В системе отсчитывается модельное время, которое используется для управления процессом обработки.

## Функционал

Интерфейс пользователя обеспечивает реализацию следующих функций:

1. **Постановка детали на обработку**
   - Добавление новой детали в очередь с указанием кода (4 символа) и времени обработки

2. **Переход к следующему моменту модельного времени**
   - Увеличение модельного времени на 1 единицу
   - Автоматическая обработка деталей в порядке очереди
   - Вывод информации о завершении обработки детали

3. **Снятие детали с обработки до завершения**
   - Имитация отказа установки
   - Прерывание текущей обработки с выводом информации

4. **Вывод списка обрабатываемых деталей**
   - Отображение всех деталей в очереди в порядке их обработки

5. **Сброс процесса моделирования**
   - Полная очистка очереди и сброс всех параметров системы

## Технические особенности

- Реализация очереди двумя способами: на основе массива и связного списка
- Проверка корректности вводимых данных
- Управление через консольное меню
- Обработка граничных случаев (переполнение очереди, пустая очередь)

## Структура проекта

- `Detail.java` - класс детали
- `Queue.java` - интерфейс очереди
- `ArrayQueue.java` - реализация очереди на массиве
- `LinkedQueue.java` - реализация очереди на связном списке
- `Main.java` - основной класс с меню и логикой работы
